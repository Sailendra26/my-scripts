#)awk command:
---------------

*)AWK is a text-processing programming language used as a command line toool to read text line by line, filter lines based on patterns or conditions, 
  extract fields, and perform calculations. 
*)The reason why we call it as a programming language means because it supports conditions, variables, loops, arrays and calculations.
  
Syntax:

awk 'pattern { action }' filename

pattern — decides which lines to select.
action — decides what to do with those lines.
filename — the file to process.

My recommendation concepts is this order:
-----------------------------------------
1. $0, $1, $2, print
2. Patterns and conditions
3. NR, NF
4. Arithmetic and comparisons
5. BEGIN, END
6. Counting and arrays




1.) $0, $1, $2, print
---------------------

Definition:
$0    -> Stores the entire current line AWK is processing.
$1    -> Stores the first field in the current line.
$2    -> Stores the second field in the current line.
print -> Prints the specified data.


Sample file: deployments.txt

nginx SUCCESS
catalogue FAILED
mongodb SUCCESS


#)Example-1: Print the entire line

Command:
awk '{print $0}' deployments.txt

Output:
nginx SUCCESS
catalogue FAILED
mongodb SUCCESS

Explanation:
$0 prints the entire current line.



#)Example-2: Print the first field

Command:
awk '{print $1}' deployments.txt

Output:
nginx
catalogue
mongodb

Explanation:
$1 prints the first field from each line.



#)Example-3: Print the second field

Command:
awk '{print $2}' deployments.txt

Output:
SUCCESS
FAILED
SUCCESS

Explanation:
$2 prints the second field from each line.



#)Example-4: Print the first and second fields

Command:
awk '{print $1, $2}' deployments.txt

Output:
nginx SUCCESS
catalogue FAILED
mongodb SUCCESS

Explanation:
$1 prints the first field.
$2 prints the second field.
The comma separates them with a space.



2.) Patterns and Conditions
----------------------------

Definition:
Pattern   -> Matches lines containing specified text.
Condition -> Checks whether a requirement is true.
{print}   -> Prints the entire matching line.


#)Example-1: Print lines containing FAILED

Command:
awk '/FAILED/ {print}' deployments.txt

Output:
catalogue FAILED

Explanation:
/FAILED/ matches lines containing the word FAILED.
{print} prints only the matching lines.



#)Example-2: Print lines where the second field is FAILED

Command:
awk '$2 == "FAILED" {print}' deployments.txt

Output:
catalogue FAILED

Explanation:
$2 == "FAILED" checks whether the second field is FAILED.
If the condition is true, {print} prints the entire line.

Note:
== means "is equal to".


Use Case:
Identify failed application deployments so a DevOps
engineer can troubleshoot them.



#)Example-3: Find HTTP 500 errors in an application log

File: access.log

10.0.0.5 GET /health 200
10.0.0.8 GET /login 500
10.0.0.9 GET /home 200
10.0.0.7 GET /api 500

Command:

awk '$4 == 500 {print}' access.log

Output:
10.0.0.8 GET /login 500
10.0.0.7 GET /api 500

Explanation:

$4 == 500 → Pattern: selects lines where the fourth field is 500.
{print}   → Action: displays the matching lines.
access.log → Input file.


3.) NR and NF
--------------

Definition:
NR -> Stores the number of the current line AWK is processing.
NF -> Stores the number of fields in the current line AWK is processing.
$0    -> Stores the entire current line AWK is processing.



#)Example-1: Print line numbers along with each line

Command:
awk '{print NR, $0}' deployments.txt

Input:
nginx SUCCESS
catalogue FAILED
mongodb SUCCESS

Output:
1 nginx SUCCESS
2 catalogue FAILED
3 mongodb SUCCESS

Explanation:
NR gives the current line number.
$0 gives the entire current line.


#)Example-2: Print the number of fields along with each line

Command:
awk '{print NF, $0}' deployments.txt

Input:
nginx SUCCESS
catalogue FAILED
mongodb SUCCESS

Output:
2 nginx SUCCESS
2 catalogue FAILED
2 mongodb SUCCESS

Explanation:
Each line has 2 fields, so NF gives 2 for every line.
$0 gives the entire current line.



#)Example-4:

Real task: Supoose Your team lead asks, “How many deployments failed?”
----------

File deployments.txt contains below:

nginx SUCCESS
catalogue FAILED
mongodb FAILED


Command:

awk '$2 == "FAILED" {count++} END {print count+0}' deployments.txt

Output:
2


Explanation:

awk → Runs the AWK text-processing tool.
$2 == "FAILED" → Checks whether the second field of each line is FAILED.
{count++} → Increments count by 1 whenever the condition is true; AWK initializes an unassigned variable to zero in this numeric context.
END → Executes the following action once after all input lines have been processed.
{print count+0} → Prints the final count; +0 ensures zero is printed if no lines match.
deployments.txt → The input file AWK processes.



#)Example-5:

Real-world DevOps example — checking disk usage:
--------------------------------------------------


Use case:
Identify filesystems with disk usage at or above 80% when investigating disk-space issues.


Command:

df -h | awk 'NR==1 || $5+0 >= 80 {print}'

Explanation:

df -h → Displays filesystem disk usage in human-readable format.
| → Passes the output of df -h to AWK.
awk → Runs the AWK text-processing tool.
NR==1 → Selects the first line (header).
|| → Means OR; either condition can be true.
$5+0 >= 80 → Converts the fifth field (e.g., 85%) to a number and checks whether it is 80 or higher.
{print} → Displays the entire line if the condition is true.
NR==1 || $5+0 >= 80 → Keeps the header OR any line where disk usage is 80% or higher.


Note:
The +0 makes a value like 85% numeric (85) for comparison.

## 3. Process Execution Types
-----------------------------

### TYPES OF PROCESSES:

We have two types of processes are :


1) Foreground Process:

*)It Runs on the terminal by default, so it occupies the terminal while a command is running. You cannot type another command until it finishes (or) 
  You stop it with " Ctrl + C "

Eg-1: sleep 100         --> The systsem sleeps for 100 seconds. It runs on foreground, that is why Terminal is blocked. so You must wait or use Ctrl+C to quit.
Eg-2: ping google.com   --> Runs in the foreground by default and continuously displays ping results until stopped.
Eg-3: dnf install httpd --> Runs in the foreground by default and displays installation progress.



2) Background process:

--> Runs in the background, allowing you to use the terminal for other commands. You should use ' & ' symbol to run any command in background.

WHY " & "?

ANS: To run a command in the background, so the terminal remains usable.

Eg-1: sleep 100 &          --> It runs this command in the background, so that terminal will be free to use for other commands.
Eg-2: cp /data /backup &   --> It runs this command in the background, so that terminal will be free to use for other commands.
Eg-3: scripts with &       --> It runs this command in the background, so that terminal will be free to use for other commands.

AWS Route 53:

*) Route → It routes DNS queries (DNS requests) to the correct destination.
*) 53 → It refers to the standard port number used by DNS.

#)What is a Hosted Zone:
-------------------------

*)A hosted zone is a container or place where it contains all DNS records.
*) These records tell DNS how to handle queries(requests) for that domain, such as which IP address or destination to use.

#)Types of Hosted Zones : 
--------------------------

1.)Public Hosted Zone : Used when the application or website should be accessible from the internet.
-----------------------

Example: 

*)You have a website www.myshop.com and you want the world to access your application
  In this case, you create a public hosted zone so users from anywhere can access the application.

2.)Private Hosted Zone: Used when the application should be accessible only inside a VPC.
-----------------------

Example:

*)You have an internal application like internal.mycompany.com that should be accessed only by servers inside a VPC.
  In this case, you create a private hosted zone, and it works only within that VPC.

#)DNS Record Types – Definition with Example :
----------------------------------------------

1.) A Record :

*)An A record connects a domain name to an IPv4 address.

Example: If your server IP is 54.20.10.5, when an user hit app.example.com connects to the 54.20.10.5 

2.) AAAA Record :

*)An AAAA record connects a domain name to an IPv6 address.

Example: If your server has an IPv6 address, you use an AAAA record to point the domain to that IPv6 address.

3.) CNAME Record :

*)A CNAME record connects one domain name to another domain name.

Example: www.example.com → myapp.alb.amazonaws.com. Here, www.example.com points to another domain, not an IP.

4. ) MX Record :

*)An MX record decides where emails of a domain should be delivered.

Example: Emails sent to @example.com are routed to the company mail server using an MX record.

5. ) TXT Record : 

*)A TXT record is used to store verification or security-related information.

Example: A TXT record is added to verify domain ownership for email or security setup.

#)HTTP Methods:
---------------

*)HTTP methods are actions that a client(Browser - Chrome, Edge, Mobile, Postman) uses to tell the server what to do with data.

1)What is a Client?

*)A client is anything that sends a request to a server.

| Method     | What it does | Meaning                      |
| ---------- | ------------ | ---------------------------- |
| **GET**    | Reads data   | Used to fetch data           |
| **POST**   | Creates data | Used to send new data        |
| **PUT**    | Updates data | Used to modify existing data |
| **DELETE** | Removes data | Used to delete data          |


#)HTTP Status Codes:
---------------------

1)What are Status Codes?

*)Status codes are numbers sent by the server to tell whether the request was successful or not.

| Code Range | Meaning                           |
| ---------- | --------------------------------- |
| **2XX**    | Request successful                |
| **3XX**    | Request successful but redirected |
| **4XX**    | Client made a mistake             |
| **5XX**    | Server has a problem              |


Important Status Codes:
------------------------

*)200 → OK
*)400 → Bad request
*)401 → Unauthorized
*)403 → Forbidden
*)404 → Not found
*)500 → Server error

*)4xx codes → client mistake
*)5xx codes → server problem

1)2XX – Success:

*)200 OK
*)The request was successful and data was returned.

2)3XX – Redirection:

*)The request is successful, but the client is redirected to another place.
  Example: website moved to a new URL.

3)4XX – Client Errors:

*)400 – Bad Request
*)The data sent by the client is wrong.

*)401 – Unauthorized
*)Username or password is missing or wrong.

*)403 – Forbidden
*)You are logged in but you are not allowed to access it.

*)404 – Not Found
*)The requested page or resource does not exist.

4)5XX – Server Errors:

*)500 – Internal Server Error
*)Something went wrong inside the server.

*)503 – Service Unavailable
*)Server is down or overloaded.

*)504 – Gateway Timeout
*)Server did not get a response from backend servers in time.
