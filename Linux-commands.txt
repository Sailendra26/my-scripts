****1)How do you change the default port number to another port number ?

If you want to change the port number for your service , the below one is just the example for your understanding but the process is same.

for Example, i am installing httpd(apache webserver ) yum install httpd -y 

httpd default port number is : 80

cd /etc/httpd/ ( httpd folder will be created inside /etc folder when you install httpd) -->  
--> ls --> cd /conf/ --> cd httpd.conf --> vim httpd.conf --> go to 47th line and change the port number to 8080 and save it --> her you must 
restart the service first because if we do any modifications in the ' conf ' folder we must restart the service and then
just try to access that webpage using ' instance public-ip address: 8080 ', it will not show the result because you have 
changed the port number in ' conf ' folder, we need to change the port number in ' Security Group ' in inbound rules(incoming traffic)

**select instance-->security-->security-group-->edit inbound-rules --> select "custom TCP" and "port-number(eg:8080)" --> select all-traffic .

Now,try to access it on browser with ' instance public-ip address: 8080 ' , you will access now.

***IMP)How to connect to the EC2 instance with the users we created in Linux ?


First you should enable the Paasword Authentication in /etc/sssh 

cd /etc/sssh --> give ' ls ' --> open sshd_config ( vim sshd_config ) --> go to the ' Paasword Authentication ' line and give ' yes ' and save it -->
Restart the service with this command ' systemctl restart sshd ' 
NOTE: you should restart the service whenever you make the changes in ' config ' file
Now, try to connect to the EC2 instance through command prompt with the user credentials ( username and password ) , you will connect now.
